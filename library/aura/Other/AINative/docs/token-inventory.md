# Token inventory

The environment variables AINative skills read, who uses them, and how each one degrades when
absent. Extracted from [CLAUDE.md](../CLAUDE.md) so the always-loaded project memory stays under
its size limit; this file is the full, authoritative text.

API keys live in `~/.claude/settings.json` under the `env` block. Tokens are **soft
requirements** — see *Secrets and environment → Tokens are soft requirements* in
[CLAUDE.md](../CLAUDE.md) for the MCP-first order of preference and the API-first exemptions.
When a new skill introduces a token dependency, add it here, update
[`plugins/shared/skills/setup-ainative/SKILL.md`](../plugins/shared/skills/setup-ainative/SKILL.md),
and document the degrade path in the skill itself.

The columns:

- **Self-serve?** = "Yes" if the user can create the value themselves (signup, settings
  page); "Team" if it has to be issued by Jerome / Rohan / eng. Team-issued tokens are
  shared dev credentials — ask in `#ai-eng` or DM Jerome / Rohan.
- **MCP fallback?** = whether the skill can degrade to an MCP server when the token is
  absent.
