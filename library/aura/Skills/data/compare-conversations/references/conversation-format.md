# Normalized conversation format

Every loader writes `conversations.jsonl`: one JSON object per line, one line per conversation.
Write this shape yourself (and load it with `load jsonl`) to compare a source that has no loader.

```json
{"id": "c-123", "group": "a", "pair_key": "row-17", "channel": "chat", "user": "Za0D…",
 "turns": [
   {"role": "user", "text": "…"},
   {"role": "assistant", "text": "…", "context": true},
   {"role": "user", "text": "…"},
   {"role": "assistant", "text": "…", "ttft_ms": 902, "latency_ms": 2400,
    "input_tokens": 21000, "output_tokens": 140, "tool_calls": 0, "llm_calls": 1, "rating": 1}
 ],
 "meta": {"prompt_files": ["coach.coachPrompterWarmth.a.txt"], "versions": ["1.22.5"]}}
```

| Field | Required | Meaning |
|---|---|---|
| `id` | yes | unique per conversation |
| `group` | yes | what is compared: arm, variant, model |
| `turns[].role` / `text` | yes | `user` or `assistant`, in order |
| `pair_key` | no | the **same input** across groups (dataset row id, QA scenario) — enables `sample --paired` |
| `channel` | no | `chat` / `voice`; metrics and sampling split by it |
| `turns[].context` | no | `true` on assistant turns that were **replayed history**, not generated by this group — shown to the reviewer, excluded from metrics |
| `turns[].ttft_ms`, `latency_ms`, `input_tokens`, `output_tokens`, `tool_calls`, `llm_calls`, `rating` | no | per-reply measures; metrics shows "—" for what a source lacks |
| `user`, `meta` | no | carried through, never printed by `metrics` |

## What each loader fills in

| Loader | group | pair_key | channel | per-reply measures |
|---|---|---|---|---|
| `experiment` | the arm on the conversation's turns | — | from `llmCall.platform` (`livekit` voice, `mobile` chat) | ttft, latency, tokens, tool calls, llm call count, rating |
| `openai-responses` | `--group NAME` | optional 2nd TAB column of the id file | `--channel` | input/output tokens, tool calls (function_call outputs); prior assistant input items marked `context` |
| `qa-transcripts` | the `### Arm X` header | `s{scenario}` | `--channel` | none |
| `qa-state` | `--group NAME` | run directory (or file stem with `--pair-by-name`) | `--channel` | none |

The file holds conversation text. It lives only in the scratch directory and `cleanup` deletes it.
